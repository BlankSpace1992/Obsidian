# AI 操作 AutoCAD 实战：用 Codex 实现自然语言画图

> 原文链接：[AI汉堡侠](https://mp.weixin.qq.com/s/wg0vsoxnKaTUPKIVj6VYmw)

---

## 一句话总结

**你说一句话，AI 直接在 AutoCAD 里把图画出来。** 不用写脚本，不用学命令，自然语言操作。

---

## 为什么做这件事

CAD 门槛不低——学会基本操作少说几个月，画复杂图没有几年功底拿不下来。行业痛点：

- 画图累，改图更累
- 重复性工作多（同样的图形画几十遍）
- 不会 CAD 的人只能求人或花钱找人画

核心问题：**能不能让 AI 帮我画？**

---

## 技术方案：Codex + AutoCAD

**Codex** 是 OpenAI 的通用 Agent，不只是写代码，还能直接操作电脑上的软件（浏览器、AutoCAD 等），调用的是 **GPT-5.5** 大模型。

架构链路：

```
自然语言指令 → Codex Agent → PowerShell COM 自动化 → AutoCAD
```

---

## 实战过程

### 环境准备

- 安装 Codex Windows 客户端（账号与 ChatGPT 一致）
- 配置网络环境（需非中国大陆/香港 IP，Codex 在这些地区无法直接使用）
- AutoCAD 2022（或其他支持 COM 的版本）

### 第一步：连接 AutoCAD

两个坑：

1. **AutoCAD 停在启动页**，COM 接口未暴露 → 需手动进入绘图界面
2. **权限问题**：普通 PowerShell 连不上管理员权限运行的 AutoCAD → Codex 自动切换到提升权限的 PowerShell

连接成功后，Codex 返回：*"AutoCAD 2022 自动化通道现在可用。你现在可以直接说要我在 CAD 里做什么。"*

### 第二步：简单图形测试

```
"帮我画一个圆形。"
→ 几秒后出现圆，中心点(0,0)，半径50，自动缩放视野

"在这个圆形中画一个内切正方形。"
→ 自动计算正方形顶点坐标，精确画出

"帮我把文件另存到桌面，文件名叫 test。"
→ 自动执行保存
```

### 第三步：复杂工程图纸

输入了一段发酵罐工程计算描述（含容积公式、高径比、各类封头参数），要求画出发酵罐示意图。

Codex 的执行过程：
1. 创建 4 个图层（罐体轮廓 / 中心线 / 尺寸线 / 文字标注）
2. 画出圆筒直段、下锥形封头斜线、上椭圆封头曲线
3. 添加中心线、尺寸标注、文字说明
4. **几十秒内画出完整发酵罐示意图**

### 第三个坑：中文显示问号

所有中文标注显示成 `????`，Codex 的排查链路：

1. 切换字体样式为宋体 → 无效
2. 用 Unicode 码点生成中文 → 无效
3. **定位根因**：PowerShell COM 创建的 `AcDbText`（单行文字）渲染有问题
4. **最终方案**：改用 `MText`（多行文字），内部强制指定 SimSun/宋体 + GB2312 字符集 → 成功

## 适用场景与限制

### 适合

- 简单的重复性图纸（标准件、示意图）
- 标准图形的批量操作
- 快速原型（概念图、草图）
- 不会 CAD 但偶尔需要画图的人

### 不适合

- 复杂的非标准图纸（需人工判断）
- 精密的工程图纸（需严格校核）
- 需要大量交互的设计

### 当前限制

- 需配置非大陆/香港网络环境（最大门槛）
- 中文字体支持目前还不完善（需用 MText 多行文字）
- 免费版每周有额度限制
- Plus 会员 $20/月，Pro 会员 $114/月
